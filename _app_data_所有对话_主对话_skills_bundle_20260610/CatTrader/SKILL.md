# CatTrader — 基于CANN评分的趋势跟踪交易系统 v3.2

## 概述

CatTrader是基于CA+CANN评分体系的量化交易决策系统。每个交易时段执行一次，读取最新38维CA统一评分（14基本面+24技术面），CANN推理后通过统一的仓位映射表完成品种筛选、杠杆管理和持仓监控。

## 数据流

```
CANN 16:00管线（每日一次）
  ├── CA全维度评分 dim1-dim38（14基本面+24技术面，ca_scorer v3.0引擎）
  ├── 回填y值 + 微调模型
  └── 全品种推理 → cann_results_{date}.json

CatTrader（每交易时段，4次/天）
  ├── 读取最新38维CA评分（来自daily_scores CSV）
  ├── 加载CANN模型推理 → 55品种综合评分s
  └── 查表 → 对比持仓 → 开仓/调仓/平仓/持有
```

**模型训练由16:00管线负责，CatTrader只做推理。**

## 仓位映射表（核心）

s ∈ [0,1] 均分为5个区间，多空对称：

```
s:  0 ════ 0.35 ════ 0.45 ════ 0.55 ════ 0.65 ════ 1
    │空0.5× │ 空0.3×  │  平仓   │ 多0.3×  │多0.5× │
    │ σ≥0.15│ σ∈[0.05,0.15)│ σ<0.05 │ σ∈[0.05,0.15) │ σ≥0.15 │
```

| 区间 | s范围 | 目标杠杆 | 含义 |
|------|-------|---------|------|
| 空0.5× | s ≤ 0.35 | 做空 0.5倍杠杆 | σ≥0.15 特别显著 |
| 空0.3× | 0.35 < s ≤ 0.45 | 做空 0.3倍杠杆 | σ∈[0.05,0.15) 一般显著 |
| 平仓 | 0.45 < s < 0.55 | 0（无仓） | σ<0.05 中性区 |
| 多0.3× | 0.55 ≤ s < 0.65 | 做多 0.3倍杠杆 | σ∈[0.05,0.15) 一般显著 |
| 多0.5× | s ≥ 0.65 | 做多 0.5倍杠杆 | σ≥0.15 特别显著 |

## 开仓约束（铁律）

**品种必须处于平仓区之外（s≤0.45或s≥0.55）才能开仓。**

此约束由双重机制保证：
1. `select_candidates()` 只从目标为LONG或SHORT的品种中筛选，中性区(Direction.NONE)品种自动排除
2. `get_target_leverage()` 将中性区(0.45<s<0.55)映射为Direction.NONE，leverage=0

中性区品种永远不会成为cmax/cmin候选，也永远不会触发开仓动作。

### 杠杆含义

每个品种独立拥有杠杆倍数作为仓位水平。例：铜0.5×表示铜品种使用0.5倍杠杆做多，焦煤0.3×表示焦煤品种使用0.3倍杠杆做空。多品种杠杆独立，不叠加计算。

## 决策推导（统一规则）

查表得到目标杠杆后，与当前持仓对比：

| 当前持仓 | 目标杠杆 | 动作 |
|---------|---------|------|
| 无仓 | ≠0 | **开仓**（仅平仓区外品种） |
| 有仓 | 0 | **平仓**（信号消失） |
| 有仓 | 同向同杠杆 | **持有** |
| 有仓 | 同向不同杠杆 | **调仓**（0.3×↔0.5×） |
| 有仓 | 反向 | **平仓+开仓**（信号反转） |

## 品种筛选

从55品种中各选1个最强信号：
- **cmax**：目标为做多的品种中s最大者
- **cmin**：目标为做空的品种中s最小者
- 无品种越过中性区则该方向空缺

## 调度

交易时段，周一至周五：

| 时段 | 时间 | 说明 |
|------|------|------|
| 日盘1 | 09:15 | 开盘15分钟后 |
| 日盘2 | 11:00 | 午盘收盘前 |
| 日盘3 | 13:30 | 午盘开盘 |
| 夜盘 | 21:15 | 夜盘开盘15分钟后 |

## 注意事项

- CatTrader仅输出决策建议，不直接下单
- 冷启动阶段（无CANN模型/无CA数据）全部s=0.5，不会产生任何开仓信号
- 同品种信号反转时先平旧仓再开新仓
- 技术面采集：TQSDK优先，失败时降级读取16:00管线CSV
