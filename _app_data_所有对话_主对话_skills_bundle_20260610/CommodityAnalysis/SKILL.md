# CommodityAnalysis (CA) - 商品期货基本面分析技能

## 描述
从一个期货交易分析师、专注于中国国内商品交易市场的视角，基于**14维度评估框架**，对给定的商品期货品种进行系统性基本面分析和评估，输出多空研判的综合打分（0-1之间）。

## 触发场景
- 用户要求对某个商品期货品种进行基本面分析、多空研判、综合评估
- 用户提到"期货分析"、"品种评估"、"多空打分"等关键词
- 日程触发（标题含"商品期货基本面分析"）

## 绝对时间基准（每次执行前必须强制执行）

当前系统时间为：`{{CURRENT_DATETIME_UTC}}`（精确到分钟）。

所有时间相关的窗口期需根据数据类型差异化处理：
- **实时数据**（价格、持仓量）：4小时窗口
- **日度数据**（现货报价、部分库存）：24小时窗口
- **周度数据**（CFTC、钢联库存）：7天窗口
- **月度数据**（经济指标）：30天窗口

## 14维度评估框架

| 序号 | 维度 | 说明 |
|------|------|------|
| 1 | 货币政策 | 主要经济体政府机构（美联储、欧央行、日央行、人民银行等）的货币政策预期和发布对该品种的影响 |
| 2 | 地缘政治 | 冲突、制裁、贸易摩擦、战争爆发/烈度变化/停火等事件对该品种的影响 |
| 3 | 产业政策 | 限产、补贴、环保督察、产能压减/释放等消息对该品种的影响 |
| 4 | 关键经济指标 | 美国和中国的CPI、FDI、PMI、PPI、M2、社融、非农、GDP等指标发布或消息对该品种的影响 |
| 5 | 市场情绪 | VIX、CFTC持仓、ETF资金流向、股市联动等（**DXY已移至维度1**） |
| 6 | 财政政策 | 专项债、基建投资、特别国债等消息对该品种的影响 |
| 7 | 供应 | 该品种的供应端分析 |
| 8 | 需求 | 该品种的需求端分析 |
| 9 | 基差 | 该品种的基差分析 |
| 10 | 跨市场 | 如有外盘（Comex、LME等），短时间内（1-24小时）外盘价格变化对该品种价格的影响 |
| 11 | **价格位置**（重构） | 价格在历史区间的相对位置、均线系统、波动率（**原"支撑位阻力位"重构**） |
| 12 | 周期性 | 季节周期性（供需淡旺季）、产业库存周期、产业检修周期、政策周期对该品种价格的影响 |
| 13 | **资金面**（新增） | 持仓量变化、仓单变化、前20会员持仓、资金流向（**实盘核心领先指标**） |
| 14 | **价差结构**（新增） | 跨期价差、contango/backwardation、月间套利信号 |

## 分析评估步骤

### 第一步：信息和数据采集

收集每个维度需要的数据和信息。

**采集方法**：web search、TQSDK（优先）、公开数据API、专业信息获取接口等。

**TQSDK 优先策略**：

对于以下维度，优先使用 TQSDK 获取实时/历史数据，失败时降级到 web search：
- **维度9 基差**：TQSDK 获取期货价格 + web search 获取现货价格
- **维度11 价格位置**：TQSDK 获取K线计算均线/20日高低/布林带
- **维度13 资金面**：TQSDK 获取持仓量/成交量
- **维度14 价差结构**：TQSDK 获取近月/远月合约价格计算价差

TQSDK 使用方式：
```python
from skills.common.tqsdk_data import TQDataProvider

with TQDataProvider() as provider:
    # 获取实时价格
    price = provider.get_realtime_price("cu")
    # 获取技术指标（含均线、布林带、20日高低）
    indicators = provider.get_technical_indicators("cu")
    # 获取持仓量/成交量
    pos_vol = provider.get_position_and_volume("cu")
    # 获取跨期价差
    spread = provider.get_main_spread("cu")
```

**全局要求**：

1. **时间精确性**：所有时间必须对应事件发生的具体情况，尽可能精确到分钟。若只能确定日期，需说明"仅能确定至日期"。

2. **来源可追溯**：信息来源必须写明可追溯来源（机构/媒体/交易所/链上平台/具体文章标题或URL）。

3. **禁止编造**：只基于可验证信息，严禁编造任何数字、事件或引语。如果没有搜索到任何可靠数据，必须在每个字段中如实体现，不得用常识或历史数据填充。

4. **固定输出格式**：每个子问题必须按以下格式输出5个字段，字段名和顺序不得变化：

```json
{
  "信息发生时间": "事件发生的具体时间（如2026-05-07 23:30 UTC），若无法精确到分钟则说明。该时间必须在窗口期内，否则标为历史背景",
  "信息来源": "...（必须列出本题检索得到的核心来源，至少1个；若完全没有找到，写"未检索到足够可信来源"）",
  "信息总结": "...（基于窗口期事实总结，若没有则写"未发现"）",
  "对市场的影响": "...（若没有显著影响则写"无直接可验证影响"，不可强行编造）",
  "这个信息能影响多久": "...（若没有则写"不适用"）"
}
```

5. **实时搜索优先**：每个子问题必须先执行实时信息搜索，再给出答案；严禁仅凭参数记忆或常识直接作答。

6. **数据留白原则**：对于数值类问题（如价格、爆仓金额、资金费率等），如果搜索结果中没有窗口期内的精确数据，必须在"信息总结"中明确说"未在窗口期内检索到对应数据"，并说明不确定性。严禁用历史均值、线性外推或相似事件数据进行编造。

7. **一致性原则**：在分析过程中，引用的价格、关键时间点等必须自洽。如果发现不同问题引用了明显矛盾的期货价格，必须标注矛盾并注明各自来源的时间戳，优先采信时间戳最接近 `{{WINDOW_END_UTC}}` 的来源。

#### 各维度搜索指引

**维度1 - 货币政策**：
- 搜索关键词：`美联储议息`、`人民银行MLF/逆回购/LPR`、`欧央行利率决议`、`美元指数`、`人民币汇率` + 品种名
- 重点关注：利率决议、官员讲话、货币政策会议纪要
- **数据窗口**：30天（经济数据为月度发布）

**维度2 - 地缘政治**：
- 搜索关键词：`地缘冲突`、`贸易摩擦`、`制裁`、`战争` + 品种相关地区
- 重点关注：中东局势、俄乌冲突、中美贸易、南海局势
- **数据窗口**：4小时（实时）

**维度3 - 产业政策**：
- 搜索关键词：品种名 + `限产`/`补贴`/`环保`/`产能`/`政策`
- 重点关注：发改委、工信部、环保部公告，行业协会通知
- **数据窗口**：7天

**维度4 - 关键经济指标**：
- 搜索关键词：`CPI`/`PMI`/`PPI`/`M2`/`社融`/`非农`/`GDP` + `最新`/`发布`
- 重点关注：中美主要经济数据发布、预期与实际偏差
- **数据窗口**：30天（月度数据）

**维度5 - 市场情绪**：
- 搜索关键词：`VIX`、`CFTC持仓`、品种名 + `资金流向`/`ETF`
- 重点关注：VIX极端读数、持仓集中度变化（**DXY已移至维度1**）
- **数据窗口**：7天（CFTC为周度数据）
- **备用来源**：文华财经CFTC数据、Eiaoil.com

**维度6 - 财政政策**：
- 搜索关键词：`专项债`/`基建投资`/`特别国债`/`财政刺激` + 品种名
- 重点关注：人大/国务院/财政部公告、地方债发行节奏
- **数据窗口**：30天

**维度7 - 供应**：
- 搜索关键词：品种名 + `产量`/`开工率`/`库存`/`进口`/`产能`
- 重点关注：产量数据、开工率变化、港口库存、进口到港量
- **数据窗口**：7天
- **推荐来源**：钢联数据(mysteel.net)、卓创资讯(sci99.com)

**维度8 - 需求**：
- 搜索关键词：品种名 + `需求`/`消费`/`出口`/`下游开工`/`表观消费`
- 重点关注：下游开工率、表观消费量、出口数据
- **数据窗口**：7天

**维度9 - 基差**：
- 搜索关键词：品种名 + `基差`/`现货价格`/`期货价格`/`升贴水`
- 重点关注：主力合约基差、基差历史分位数
- **数据窗口**：24小时
- **数据源优先级**：
  1. **TQSDK（推荐）**：获取期货价格 + web search 获取现货价格
  2. **新浪财经现货报价** + 期货行情
  3. 钢联/卓创专业页面
  4. 交易所仓单价格

**维度10 - 跨市场**：
- 搜索关键词：品种名 + `外盘`/`LME`/`COMEX`/`ICE`/`国际价格`
- 重点关注：外盘主力合约价格变动、内外盘比值
- **数据窗口**：4小时

**维度11 - 价格位置**（重构自"支撑位阻力位"）：
- 搜索关键词：品种名 + `技术分析`/`均线系统`/`波动率`
- 重点关注：价格在历史区间的相对位置、均线系统、波动率指标
- **数据窗口**：24小时
- **数据源优先级**：
  1. **TQSDK（推荐）**：获取K线数据，直接计算MA5/MA10/MA20/MA60、布林带、20日高低点
  2. 东方财富期货行情页
  3. 同花顺技术分析页、文华财经
- **注意**：仅作为另类数据补充，不作为主要决策依据

**维度12 - 周期性**：
- 搜索关键词：品种名 + `季节性`/`淡旺季`/`检修季`/`库存周期`
- 重点关注：当前所处季节性阶段、历年同期表现、检修计划
- **数据窗口**：30天

**维度13 - 资金面**（新增）：
- 搜索关键词：品种名 + `持仓量`/`仓单变化`/`前20会员`/`资金流向`
- 重点关注：
  - 持仓量增加+价格上涨 = 增仓做多信号
  - 持仓量增加+价格下跌 = 增仓做空信号
  - 仓单增减变化
  - 前20会员多空力量对比
- **数据窗口**：7天
- **数据源优先级**：
  1. **TQSDK（推荐）**：获取实时持仓量、成交量
  2. 交易所官网持仓排名
  3. 东方财富期货、大连/郑州商品交易所

**维度14 - 价差结构**（新增）：
- 搜索关键词：品种名 + `跨期价差`/`contango`/`backwardation`/`月间套利`
- 重点关注：
  - 近月-远月跨期价差（01/05/09合约价差）
  - 价差历史分位数（判断极端结构）
  - contango（熊市结构）vs backwardation（牛市结构）
- **数据窗口**：7天
- **数据源优先级**：
  1. **TQSDK（推荐）**：获取近月/远月合约价格，直接计算价差
  2. 交易所行情页
  3. Wind金融终端、文华财经

### 第二步：维度评分

在每个维度根据获取到的数据和信息，分析这些数据和信息对该期货品种价格的影响，然后根据影响程度打分：
- **最大利多**：1分
- **中性**：0.5分
- **最大利空**：0分
- 介于中间的按实际影响程度在0~1之间赋分

评分时需给出简要评分理由。

输出：**14维度打分表**

| 维度 | 得分 | 评分理由 |
|------|------|----------|
| 1 货币政策 | x.xx | ... |
| 2 地缘政治 | x.xx | ... |
| ... | ... | ... |
| 12 周期性 | x.xx | ... |
| 13 资金面 | x.xx | ... |
| 14 价差结构 | x.xx | ... |

---

### 第三步：权重评估

考虑当前的时间（月份、日期）和该品种的特点，评估目前每个维度的权重。

权重调整原则：
- **周期性**：某些时段产品周期性对价格影响大，则增加周期性维度权重
- **突发事件**：某些时点突发的货币政策/地缘政治/产业政策影响特别大，则加大对应维度权重
- **供需格局**：供需严重失衡时，加大供应/需求维度权重
- **市场极端**：市场情绪极端时，加大市场情绪维度权重
- **资金面**：持仓量/仓单异常时，加大资金面维度权重

所有维度权重之和 = 1.0

输出：**14维度权重表**

| 维度 | 权重 | 权重调整理由 |
|------|------|--------------|
| 1 货币政策 | 0.xx | ... |
| 2 地缘政治 | 0.xx | ... |
| ... | ... | ... |
| 12 周期性 | 0.xx | ... |
| 13 资金面 | 0.xx | ... |
| 14 价差结构 | 0.xx | ... |

---

### 第四步：加权平均评估

根据上述各维度评分和各维度权重，进行加权平均得到综合得分。

$$综合得分 = \sum_{i=1}^{14} (得分_i \times 权重_i)$$

输出格式：

| 维度 | 得分 | 权重 | 加权得分 |
|------|------|------|----------|
| 1 货币政策 | x.xx | 0.xx | x.xx |
| 2 地缘政治 | x.xx | 0.xx | x.xx |
| ... | ... | ... | ... |
| 14 价差结构 | x.xx | 0.xx | x.xx |
| **综合得分** | | | **x.xx** |

**多空研判解读**：
- 0.00 - 0.30：强利空，建议空头思路
- 0.30 - 0.45：偏空，谨慎偏空操作
- 0.45 - 0.55：中性，观望为主
- 0.55 - 0.70：偏多，谨慎偏多操作
- 0.70 - 1.00：强利多，建议多头思路

---

### 第五步：操作方案生成（P1新增）

基于综合得分和关键维度数据，生成可操作的交易方案。

#### 5.1 方向判断

根据综合得分确定建议方向：
- 综合得分 ≥ 0.55：多头方向
- 综合得分 ≤ 0.45：空头方向
- 0.45 < 综合得分 < 0.55：观望

**多维度交叉确认**（必须满足至少2条才可开仓）：
- 综合得分方向与资金面（维度13）信号一致
- 综合得分方向与价差结构（维度14）信号一致
- 基差（维度9）支持该方向（如做多时基差为正=现货升水）

#### 5.2 入场方案

| 项目 | 生成规则 |
|------|----------|
| 建议入场区间 | 维度11（价格位置）中的关键支撑位（做多）或阻力位（做空），取TQSDK计算的20日高低点、布林带上下轨、MA支撑/阻力 |
| 入场触发条件 | 价格触及入场区间 ± 0.5%范围 + 资金面（维度13）持仓量方向确认 |
| 首次入场仓位 | 根据置信度确定：综合得分偏离0.5越远仓位越大，0.55-0.60建议10%，0.60-0.70建议15%，0.70+建议20%（空头同理） |

#### 5.3 止损方案

| 项目 | 生成规则 |
|------|----------|
| 止损价位 | 做多：维度11计算的20日低点 - 1个ATR；做空：20日高点 + 1个ATR。若无ATR数据，取关键支撑/阻力位下方/上方1-2% |
| 止损幅度 | 一般品种不超过3%，高波动品种（如原油、黄金）不超过5% |
| 止损后观察 | 评估是否为假突破，如资金面未反转可考虑二次入场 |

#### 5.4 止盈与加仓

| 项目 | 生成规则 |
|------|----------|
| 第一目标位 | 做多：维度11计算的上方阻力位；做空：下方支撑位 |
| 第二目标位 | 结合维度14（价差结构）的极端分位数和维度9（基差）的历史均值回归位 |
| 加仓条件 | 盈利达到止损幅度的1.5倍后 + 资金面持续确认，加仓不超过首次仓位 |
| 移动止损 | 盈利达到第一目标后，止损移至成本价；达到第二目标后，止损移至第一目标位 |

#### 5.5 操作方案约束

- **中性区间不开仓**：综合得分在0.45-0.55时，仅输出观望建议
- **维度冲突降仓**：资金面/价差结构与综合得分方向冲突时，仓位减半
- **无数据不开仓**：维度11（技术结构）和维度13（资金面）均无TQSDK数据时，操作方案标注"数据不足，不建议开仓"
- **突发风险预警**：维度1（货币政策）或维度2（地缘政治）有重大事件待发布时，标注"建议事件落地后再操作"

## 输出产物

1. **14维度信息采集报告**：每个维度的子问题按固定5字段格式输出
2. **14维度打分表**：含得分和评分理由
3. **14维度权重表**：含权重和调整理由
4. **综合评估表**：含加权得分和多空研判
5. **操作方案**：含方向判断、入场/止损/止盈/加仓方案
6. 所有产物保存为 `.md` 文件，存放于 `./商品期货分析/{品种名}/` 目录下，文件名含日期

## 注意事项

- 所有搜索必须实时执行，严禁使用过时缓存
- 如果某个维度确实搜索不到任何窗口期信息，该维度默认评分为0.5（中性），权重适当降低
- 分析过程中发现不同来源数据矛盾时，必须标注矛盾并说明取舍依据
- 最终报告末尾必须附上免责声明：本分析仅供参考，不构成投资建议
- **窗口期差异化**：实时数据4h窗口、周度数据7天窗口、月度数据30天窗口
