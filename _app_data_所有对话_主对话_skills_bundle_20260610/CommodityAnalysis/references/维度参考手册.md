## 维度7：供应

### ⚠️ 评分方向（必读）
- **供应偏紧 → 利多 → 高分（→1）**：产量下降、库存去化、进口减少、开工率低、产能受限 → 价格支撑强
- **供应宽松 → 利空 → 低分（→0）**：产量增加、库存累积、进口放量、开工率高、产能释放 → 价格承压
- 常见错误：把"供应紧张"当作负面打低分 ❌——从交易视角，供应紧张是做多逻辑

### 分析要素
- 国内产量及同比变化
- 开工率（高炉开工率、炼厂开工率等）
- 进口量及到港量
- 港口库存/社会库存/厂内库存
- 产能投放计划
- 检修计划

### 数据窗口
- 周度数据，7天窗口

### 数据来源
- **主数据源**：钢联数据(mysteel.net)
- **备用数据源**：卓创资讯(sci99.com)、我的农产品网、海关总署

## 维度8：需求

### ⚠️ 评分方向（必读）
- **需求旺盛 → 利多 → 高分（→1）**：下游开工率高、表观消费增长、出口强劲、终端订单充足 → 价格支撑强
- **需求疲弱 → 利空 → 低分（→0）**：下游开工率低、消费下滑、出口萎缩、终端订单不足 → 价格承压

### 分析要素
- 表观消费量
- 下游开工率
- 出口数据
- 终端行业数据（地产、汽车、家电等）
- 成交量/提货量

## 维度9：基差

### 核心概念
- 基差 = 现货价格 - 期货价格
- 正基差（期货贴水）：现货强于期货，利多
- 负基差（期货升水）：期货强于现货，利空
- 基差走强：利多
- 基差走弱：利空

### 分析方法
- 对比基差历史分位数
- 关注基差与价格的组合信号
- 基差极值往往预示方向反转

### 数据窗口
- 日度数据，24小时窗口

### 推荐数据源
- **主数据源**：新浪财经现货报价
- **备用数据源**：钢联/卓创专业页面、交易所仓单数据

## 维度11：价格位置（重构自"支撑位阻力位"）

### 核心关注点
- 价格在历史区间的相对位置（如20%分位数=低估）
- 均线系统（5日、10日、20日、60日）
- 波动率指标
- 价格形态

### 信号判断
- 价格在历史低位 → 利多信号
- 价格在历史高位 → 利空信号
- 均线多头排列 → 趋势偏多
- 均线空头排列 → 趋势偏空
- 波动率极低 → 可能酝酿突破

### 与原维度的区别
- 不再关注传统"支撑位/阻力位"的绝对价格
- 关注价格在自身历史分布中的相对位置
- 作为另类数据补充，不作为主要决策依据

### 数据窗口
- 日度数据，24小时窗口

### 推荐数据源
- **主数据源**：东方财富期货行情页
- **备用数据源**：同花顺技术分析页、文华财经

## 维度13：资金面（新增）

### 核心指标
- **持仓量变化**：同比、环比变化
- **仓单变化**：交易所仓单周度增减
- **前20会员持仓**：多空力量对比
- **沉淀资金**：品种资金净流入/流出
- **龙虎榜**：机构席位净买卖

### 实战信号（核心）
| 价格变化 | 持仓量变化 | 研判 |
|----------|-----------|------|
| 上涨 | 增仓 | 上涨趋势确认，多头跟进 |
| 上涨 | 减仓 | 多头平仓，反弹不可持续 |
| 下跌 | 增仓 | 下跌趋势确认，空头跟进 |
| 下跌 | 减仓 | 空头平仓，底部可能形成 |

### 仓单信号
- 仓单增加 → 现货压力增大，期货贴水可能扩大
- 仓单减少 → 现货紧张，可能推动期货向现货回归

### 数据窗口
- 周度数据，7天窗口

### 推荐数据源
- **主数据源**：交易所官网持仓排名
- **备用数据源**：东方财富期货、大连/郑州商品交易所

## 维度14：价差结构（新增）

### 核心概念
- **跨期价差**：近月合约 - 远月合约
- **Contango**：远月 > 近月（远月升水），供过于求的熊市结构，持有成本为正
- **Backwardation**：远月 < 近月（远月贴水），供不应求的牛市结构，现货紧缺
- **月间套利信号**：价差偏离历史均值时的套利机会

### 实战信号
- Backwardation结构 + 现货紧张 → 坚定做多
- Contango结构 + 现货宽松 → 坚定做空
- 价差极端偏离 → 关注均值回归机会

### 常见价差
- **01/05/09合约价差**：螺纹、玉米等品种的季月结构
- **跨品种价差**：螺纹-热卷、玉米-淀粉
- **内外盘价差**：进口盈亏

### 数据窗口
- 周度数据，7天窗口

### 推荐数据源
- **主数据源**：交易所行情页（查看各合约价差）
- **备用数据源**：Wind金融终端、文华财经
