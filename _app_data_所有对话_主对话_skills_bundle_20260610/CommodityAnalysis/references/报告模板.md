## 五、操作方案

> **基于综合得分和技术结构的操作建议，仅供参考，不构成投资建议**

### 方向判断

- **建议方向**：多头 / 空头 / 观望
- **方向依据**：综合得分X.XX（偏多/偏空/中性）+ 资金面信号 + 价差结构信号

### 入场方案

| 项目 | 内容 |
|------|------|
| 建议入场区间 | 基于价格位置（维度11）的关键支撑/阻力位推算 |
| 入场触发条件 | 价格触及入场区间 + 资金面（维度13）确认信号 |
| 首次入场仓位 | 建议不超过总资金的 X%（根据综合得分偏离0.5的程度和置信度确定） |

### 止损方案

| 项目 | 内容 |
|------|------|
| 止损价位 | 基于技术结构关键位（如20日低点/高点、布林带边界） |
| 止损幅度 | 建议不超过 X%（根据品种波动率调整） |
| 止损后观察 | 是否反转信号，是否二次入场 |

### 止盈与加仓

| 项目 | 内容 |
|------|------|
| 第一目标位 | 基于技术结构上方/下方关键位 |
| 第二目标位 | 基于价差结构（维度14）和基差（维度9）的极限位置 |
| 加仓条件 | 盈利X%后 + 资金面持续确认，加仓不超过首次仓位 |
| 移动止损 | 盈利达到第一目标后，止损移至成本价 |

### 风险提示

- 本操作方案基于当前时点的基本面和技术面分析，市场条件变化时需及时调整
- 仓位和止损幅度仅为参考建议，实际操作需结合个人风险承受能力
- 关注维度1（货币政策）和维度2（地缘政治）的突发风险，此类风险可能导致止损失效
- 综合得分在0.45-0.55区间时，建议观望为主，不主动开仓
