- BTC交易所余额持续下降 → 中长期利多（供不应求）

## 维度7：链上供应

### ⚠️ 评分方向（必读）
- **供应趋紧 → 利多 → 高分（→1）**：交易所余额下降、鲸鱼增持、解锁量小
- **供应宽松 → 利空 → 低分（→0）**：交易所余额上升、鲸鱼减持、大额解锁临近

### 分析要素
- **交易所余额**：
  - BTC/ETH在交易所的余额趋势（周度变化）
  - 余额下降=持有者提币=self-custody=强利多
- **鲸鱼持仓**：
  - >1000 BTC地址数量变化
  - >1%供应量地址的持仓变化
- **代币解锁**：
  - TokenUnlocks日历（未来7/30天解锁量和价值）
  - 大额解锁临近时的提前抛售风险
- **通胀/发行率**：
  - PoS币种的年通胀率（ETH~0.5%, SOL~5%）
  - BTC年通胀率~0.8%（固定且极低）

### 数据窗口
- 周度数据，7天窗口

### 推荐数据源
- CoinGecko on-chain data
- CryptoQuant（交易所余额）
- Glassnode免费报告
- TokenUnlocks.app

## 维度9：资金费率/基差

### 核心概念
- 资金费率 = 永续合约多头定期支付给空头的费用（或反向）
- 正费率 → 多头支付空头 → 市场偏多 → 但过高=拥挤
- 负费率 → 空头支付多头 → 市场偏空 → 但过低=逼空机会
- 基差 = 现货价格 - 永续合约价格
  - 正基差（合约贴水现货）→ 利多
  - 负基差（合约升水现货）→ 正常，但过大=利空

### 实战信号（关键）
| 资金费率 | 分位数 | 信号 |
|----------|--------|------|
| >0.1%（极端正值） | >95%分位 | 🚨 多头极度拥挤，警惕回调/插针 |
| 0.05%-0.1% | 75-95%分位 | 偏多但需警惕 |
| -0.05%~0.05% | 正常 | 正常区间 |
| <-0.05% | <25%分位 | 偏空 |
| <-0.1%（极端负值） | <5%分位 | 🚨 空头极度拥挤，逼空做多机会 |

### ⚠️ 这是USDT永续最核心的维度之一
- 资金费率是"市场持仓成本的真实反映"
- 极端负费率 + OI增加 = 强做多信号（空头拥挤，一反弹就逼空）
- 极端正费率 + OI增加 = 警惕回调（多头拥挤，获利平仓引发踩踏）

### 数据窗口
- 日度数据，24小时窗口

### 推荐数据源
- **主数据源**：Binance API `GET /fapi/v1/fundingRate`
- **备用数据源**：Coinglass、CoinGecko

## 维度13：合约资金流

### 核心指标
- **OI（未平仓合约）**：持仓量变化是趋势确认的关键
- **OI+价格组合**（核心实战信号）：

| 价格变化 | OI变化 | 研判 |
|----------|--------|------|
| 上涨 | 增仓 | ✅ 多头趋势确认，上涨可持续 |
| 上涨 | 减仓 | ⚠️ 空头平仓推动，反弹脆弱 |
| 下跌 | 增仓 | ✅ 空头趋势确认，下跌可持续 |
| 下跌 | 减仓 | ⚠️ 多头平仓，可能见底 |

- **多空持仓比（LSR）**：
  - LSR > 2.5 → 过度做多（警惕）
  - LSR < 0.8 → 过度做空（逼空机会）
- **清算热力图**：
  - 上方/下方清算聚集区 → 磁吸效应（价格倾向于"扫"这些区域）
- **大额转账**（>$1M）：鲸鱼向/从交易所转账

## 维度14：期限结构

### 核心概念
- **跨期价差** = 当季合约价格 - 当周合约价格
- **Contango**：远月 > 近月（升水）→ 正常牛市结构，持有成本为正
- **Backwardation**：远月 < 近月（贴水）→ 现货紧张，强利多信号
- **价差极端**：当跨期价差严重偏离历史均值 → 均值回归交易机会

### Binance交割合约类型
| 合约 | 到期 | 代码示例 |
|------|------|----------|
| 当周 | 本周五 08:00 UTC | BTCUSDT_250627 |
| 次周 | 下周五 08:00 UTC | BTCUSDT_250704 |
| 当季 | 季度最后一个周五 | BTCUSDT_250926 |
| 次季 | 下季度最后一个周五 | BTCUSDT_251226 |

### 实战信号
- Backwardation（双周>单周）+ 低资金费率 → 强利多
- Contango极度陡峭（季>周远超历史均值）→ 可能酝酿回调
- 价差收敛速度异常 → 期限套利资金大规模介入信号

### 数据窗口
- 周度数据，7天窗口

### 推荐数据源
- **主数据源**：Binance API 交割合约价格
- **备用数据源**：Coinglass futures data、Deribit
