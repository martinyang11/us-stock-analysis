# 14维度详细参考手册 — 美股TradFi永续合约版

## 维度1：货币政策

### 核心关注点
- 美联储：FOMC利率决议、点阵图、鲍威尔讲话、会议纪要
- 联邦基金利率期货（CME FedWatch）：加息/降息概率
- DXY（美元指数）：影响跨国企业营收和资金流向
- 实际利率（TIPS收益率）：影响股票风险溢价
- 缩表/扩表（QT/QE）：Fed资产负债表变化

### 对不同板块的影响逻辑
| 板块 | 影响逻辑 |
|------|----------|
| 科技/成长股 | 对利率最敏感 — 高利率=折现率高=估值受压 |
| 金融 | 高利率利多（净息差扩大） |
| 消费/防御 | 中低敏感 |
| 小盘股 | 高利率利空（融资成本高） |
| 利率敏感ETF | TLT（债）/XLU（公用事业）直接受益于降息 |

### 关键信号
- FOMC鸽派转鹰 → 利率↑ → 科技股估值↓（利空NVDA/MSFT等）
- FOMC鹰派转鸽 → 降息预期 → 成长股反弹（利多）
- QT结束信号 → 流动性边际改善 → 全市场利多
- DXY走强 → 跨国企业海外营收折算减少 → 利空

### 数据窗口：30天

## 维度3：财政政策

### 核心关注点
- 联邦预算/赤字规模
- 债务上限谈判（市场波动源）
- 企业税率变化（直接冲击EPS）
- 资本利得税改革
- 财政刺激/基建法案

### 影响逻辑
- 减税法案 → 企业盈利↑ → 利多
- 赤字扩大 → 长期利率↑ → 估值↓（利空）
- 债务上限僵局 → 避险 → 短期利空
- 基建支出 → 利多工业/材料板块

### 数据窗口：30天

## 维度6：盈利能力

### ⚠️ 评分方向
- **盈利强劲 → 高分（→1）**：营收/利润超预期、利润率扩张
- **盈利疲弱 → 低分（→0）**：营收/利润miss、利润率收缩

### 核心指标
| 指标 | 含义 | 关注点 |
|------|------|--------|
| Revenue Growth YoY | 营收同比增速 | 加速/减速趋势 |
| EPS | 每股收益 | vs 预期 |
| Gross Margin | 毛利率 | 定价权和成本控制 |
| Operating Margin | 运营利润率 | 经营效率 |
| Net Margin | 净利率 | 综合盈利水平 |
| ROE | 净资产收益率 | 股东资本回报 |
| ROIC | 投入资本回报率 | 与WACC比较 |
| FCF Yield | 自由现金流收益率 | 真金白银 |

### 推荐数据源
- SEC EDGAR（10-Q/10-K原文）
- Yahoo Finance Statistics
- Seeking Alpha Earnings

### 数据窗口：30天（覆盖最新财报）

## 维度7：估值安全边际

### ⚠️ 评分方向
- **估值低估 → 高分（→1）**：PE/PB显著低于历史均值/行业
- **估值高估 → 低分（→0）**：PE/PB显著高于历史均值/行业

### 核心估值指标
| 指标 | 当前应关注 |
|------|-----------|
| TTM PE | 过去12个月实际PE |
| Forward PE | 基于下一年盈利预期的PE |
| PEG Ratio | PE ÷ 盈利增速（<1=低估） |
| PB Ratio | 市净率（金融股更重要） |
| PS Ratio | 市销率（高增长亏损公司用） |
| EV/EBITDA | 企业价值倍数 |

### 分位数判断
- PE在5年均值-1σ以下 → 估值偏低（利多）
- PE在5年均值+1σ以上 → 估值偏高（利空）
- 需结合行业特征：科技PE天然高、金融PB为主

### 数据窗口：24小时（价格实时变动）

## 维度9：合约资金流（Binance API 优先）

### ⚠️ 这是永续合约特有的关键维度

### OI+价格组合（核心实战信号）
| 价格 | OI | 研判 |
|------|-----|------|
| 涨 | 增仓 | ✅ 多头趋势确认，趋势可持续 |
| 涨 | 减仓 | ⚠️ 空头平仓推动，反弹脆弱 |
| 跌 | 增仓 | ✅ 空头趋势确认，趋势可持续 |
| 跌 | 减仓 | ⚠️ 多头平仓踩踏，可能超卖 |

### 资金费率信号
- 正费率（多头支付空头）→ 市场偏多，但>0.1%=拥挤→警惕回调
- 负费率（空头支付多头）→ 市场偏空，但<-0.1%=拥挤→逼空机会
- 注意：TradFi永续费率一般低于加密（波动小）

### 推荐数据源
- **主数据源**：Binance API `open_interest` / `funding_rate`
- 备用：Coinglass

### 数据窗口：4小时（实时）

## 维度10：机构动向

### 核心关注点
- **ETF流量**：对应ETF（如NVDA→SMH/SOXX、个股→SPY/QQQ）的资金流入流出
- **13F持仓**：每季度公布，知名基金（如Baillie Gifford/Cathie Wood）的增持/减持
- **内部人交易**：CEO/CFO/Director的买卖（>3人同向=强信号）
- **做空比例**（Short Float）：过高=逼空潜力；过低=缺乏看空对立面
- **机构持股比例**：机构持股>70%=机构认可；<30%=散户主导

### 信号强度
| 信号 | 持续性 |
|------|--------|
| 知名基金13F大幅增持 | 3-6个月中期信号 |
| CEO大额买入 | 强烈看多信号 |
| 内部人集体减持 | 警惕风险 |
| ETF持续多日净流入 | 短期（日-周） |

### 数据窗口：7天

## 维度11：市场情绪

### 核心指标
| 指标 | 极端看多区域 | 极端看空区域 | 含义 |
|------|------------|------------|------|
| VIX | <12（自满） | >25（恐慌） | >25=反向做多机会 |
| Put-Call Ratio | <0.6 | >1.0 | >1.0=过度看空 |
| AAII Bull-Bear Spread | >30% | <-20% | 反向指标 |
| CNN Fear & Greed | >75 | <25 | 极端值=反转信号 |

### 注意
- VIX是核心中的核心 — 美股"恐慌指数"
- 极端恐慌时（VIX>30），往往是买点
- 自满时（VIX<12），警惕"黑天鹅"

### 数据窗口：4小时

## 维度12：技术结构（Binance API 优先）

### 核心关注点
- **均线系统**：MA20/MA50/MA200排列
- **布林带**：价格在带中的位置、带宽收缩
- **ATR**：平均真实波幅→止损参考
- **RS vs SPY**：相对强弱（个股跑赢/跑输大盘）
- **量价关系**：放量突破/缩量整理

### 信号判断
- MA20>MA50>MA200（多头排列）→ 强趋势偏多
- MA20<MA50<MA200（空头排列）→ 强趋势偏空
- 布林带宽收窄 + 低ATR → 酝酿突破
- 相对SPY走强且趋势持续 → 资金青睐

### 推荐数据源
- **主数据源**：Binance API K线数据
- 备用：TradingView

### 数据窗口：24小时

## 维度13：公司治理

### 核心关注点
- **董事会独立性**：独立董事比例
- **股东回报**：
  - 股票回购计划规模（占市值%）
  - 分红收益率 + 分红增长历史
- **高管薪酬**：与股东利益是否对齐
- **股权结构**：创始人控制vs分散持股

### 信号
- 回购计划大幅增加 → 管理层认为股价低估 → 利多
- 分红连续增长 >10年 → "分红贵族" → 质量信号
- CEO减持 → 可能利空（但需区分是计划内还是恐慌性）

### 数据窗口：30天

## 维度14：事件驱动

### 核心事件日历
| 事件类型 | 影响时长 | 波动预期 |
|----------|---------|---------|
| 季度财报发布 | 1-3天 | 高（±5-15%） |
| FDA药品审批决定 | 1天 | 极高（±20-50%） |
| 重大产品发布 | 1-5天 | 中高 |
| M&A公告 | 1-10天 | 高 |
| SEC调查/诉讼 | 1-30天 | 高 |
| 投资者日/Analyst Day | 1-3天 | 中 |
| 拆股/特别分红 | 1-3天 | 中 |

### 分析要点
- 提前标注未来7-30天的事件日历
- 分析事件概率（如FDA批准概率）和定价程度
- 事件后：是否"buy the rumor, sell the news"
