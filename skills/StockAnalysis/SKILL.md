# StockAnalysis (SA) — 美股TradFi永续合约14维度分析技能

## 描述
从美股分析师的视角，基于**14维度评估框架**，对 gTrade（Gains Network）去中心化永续合约上的传统金融（TradFi）品种进行系统性基本面分析，覆盖宏观、行业、公司、市场、治理催化五大板块，输出多空研判综合打分（0-1之间）。

**品种范围**：gTrade Arbitrum 上架的 **29 个** TradFi 标的，包括截图指定的 22 只美股/股票类标的与 7 只指数/ETF 类标的。gTrade 是链上合成资产平台，价格通过 Chainlink DON 喂价跟踪标的现货。

## 触发场景
- 用户要求对某个TradFi永续品种进行基本面+技术面分析
- 用户提到"美股分析"、"永续合约分析"、"TradFi打分"等关键词
- 日程触发（标题含"StockAnalysis"或"美股永续分析"）

5. **实时搜索优先**：每个子问题必须先执行实时信息搜索，再给出答案；严禁仅凭参数记忆或常识直接作答。

#### 各维度搜索指引

**维度1 - 货币政策**：
- 搜索关键词：`Fed interest rate decision`、`FOMC minutes latest`、`DXY dollar index`、`real yield TIPS`、`Fed balance sheet QT`
- 重点关注：FOMC利率决议/点阵图、CME FedWatch加息/降息概率、鲍威尔及官员讲话、DXY走势
- **对不同板块的影响**：
  - 科技/成长股（NVDA/MSFT/TSLA）：对利率最敏感 — 高利率=折现率高=估值受压
  - 金融（如SOFI）：高利率利多（净息差扩大）
  - 商品（XAU/XAG）：美元实际利率反向关系最强
- 推荐来源：CME FedWatch（fedwatch.cmegroup.com）、FRED（fred.stlouisfed.org）
- **数据窗口**：30天（经济数据为月度发布）

**维度2 - 经济周期**：
- 搜索关键词：`US GDP latest`、`nonfarm payrolls latest`、`CPI release latest`、`ISM PMI`、`yield curve 2s10s spread`
- 重点关注：非农/CPI/GDP发布及超预期/不及预期、ISM PMI是否在50以上、收益率曲线是否倒挂
- "软着陆"叙事 → 全市场利多；衰退担忧（PMI<50 + 失业率↑）→ 利空周期股
- "Goldilocks"（温和增长+低通胀）→ 最优美股环境
- 推荐来源：BLS.gov、BEA.gov、ISM World
- **数据窗口**：30天（月度数据）

**维度3 - 财政政策**：
- 搜索关键词：`federal budget deficit`、`debt ceiling US`、`tax policy US corporate`、`fiscal stimulus bill`
- 重点关注：债务上限谈判（市场波动源）、企业税率变化（直接冲击EPS）、基建/财政刺激法案
- 减税法案 → 企业盈利↑ → 利多；赤字扩大 → 长期利率↑ → 估值↓（利空）
- 推荐来源：CBO.gov、Treasury.gov、Congress.gov
- **数据窗口**：30天

**维度4 - 行业景气度**：
- 搜索关键词：品种所属行业 + `sector performance 2026`、`sector rotation`、`industry outlook`
- GICS行业映射参照：NVDA/INTC/AMD→半导体、META/GOOGL→数字广告/互联网、AMZN→电商/云、TSLA→电动车、COIN/HOOD→加密金融、LLY→医药、DIS/HD→消费、ORCL/CSCO→企业IT、XAU/XAG/CL→商品
- 关注：费城半导体指数(SOX)、行业ETF资金流、行业轮动（增长→价值/防御→周期）
- 经济扩张期→周期股跑赢；利率下降→成长/科技跑赢
- **数据窗口**：7天

**维度5 - 比较优势**：
- 搜索关键词：品种公司名 + `market share`、`competitive advantage`、`moat`、`industry leader`
- 分析框架：市场份额绝对值及趋势、技术壁垒/网络效应/品牌/专利/规模经济护城河、竞品对比
- 关注：管理层在Earnings Call中对竞争位置的表述、行业排名变化
- 推荐来源：Gartner Magic Quadrant、IDC Market Share、公司10-K Business章节
- **数据窗口**：30天

**维度6 - 盈利能力**：

⚠️ **评分方向（必读）**：
- **盈利强劲 → 高分（→1）**：营收/利润超预期增长、利润率扩张、FCF健康
- **盈利疲弱 → 低分（→0）**：营收/利润下滑或miss、利润率收缩、FCF恶化

核心指标：

| 指标 | 含义 | 关注点 |
|------|------|--------|
| Revenue Growth YoY | 营收同比增速 | 加速/减速趋势 |
| EPS | 每股收益 | vs 预期值 |
| Gross Margin | 毛利率 | 定价权和成本控制能力 |
| Operating Margin | 运营利润率 | 经营效率 |
| Net Margin | 净利率 | 综合盈利水平 |
| ROE | 净资产收益率 | 股东资本回报效率 |
| ROIC | 投入资本回报率 | 与WACC比较（>WACC=创造价值） |
| FCF Yield | 自由现金流收益率 | "真金白银"，比EPS更难操纵 |

搜索关键词：品种公司名 + `quarterly earnings results`、`revenue growth`、`profit margin`、`ROE`、`free cash flow`
推荐来源：SEC EDGAR 10-Q/10-K原文、Yahoo Finance Statistics、Seeking Alpha Earnings
**数据窗口**：30天（覆盖最新财报季）

**维度7 - 估值安全边际**：

⚠️ **评分方向（必读）**：
- **估值低估 → 高分（→1）**：PE/PB显著低于5年均值和行业中位数
- **估值高估 → 低分（→0）**：PE/PB显著高于5年均值和行业中位数

核心估值指标：

| 指标 | 适用场景 | 关注点 |
|------|---------|--------|
| TTM PE | 盈利稳定的成熟公司 | 当前 vs 5年均值分位 |
| Forward PE | 所有公司 | 基于未来预期的估值 |
| PEG Ratio | 成长型公司 | <1 = 低估（盈利增速>PE） |
| PB Ratio | 金融股（如SOFI） | 资产价值评估 |
| PS Ratio | 高增长亏损公司 | 营收估值 |
| EV/EBITDA | 重资产行业 | 企业价值倍数 |

分位数判断：
- PE在5年均值-1σ以下 → 估值偏低（利多）
- PE在5年均值+1σ以上 → 估值偏高（利空）
- 需结合行业特征：科技PE天然高于公用事业，应跨行业对比

搜索关键词：品种代码 + `PE ratio`、`forward PE`、`PEG ratio`、`valuation vs peers vs history`
推荐来源：Yahoo Finance Statistics、Macrotrends、Gurufocus
**数据窗口**：24小时（价格实时变动）

**维度8 - 盈利预期**：

⚠️ **评分方向（必读）**：
- **预期上调 → 高分（→1）**：Guidance上调、分析师集体升级、盈利预期加速上修
- **预期下调 → 低分（→0）**：Guidance下调、分析师集体降级、盈利预期持续下修

关键信号及强度：

| 信号 | 强度 | 持续性 |
|------|------|--------|
| Earnings Beat >10% + Guidance Raise | ⭐⭐⭐⭐⭐ | 强利多，持续1-3月 |
| Earnings Beat 但Guidance不变 | ⭐⭐⭐ | 中性，短期 |
| 多家分析师连续上调EPS预期（>5家） | ⭐⭐⭐⭐ | 中期利多 |
| Earnings Miss + Guidance Cut | ⭐⭐⭐⭐⭐(空) | 强利空，持续1-3月 |
| Insider CEO/CFO买入(>3人) | ⭐⭐⭐⭐ | 强看多信号 |

搜索关键词：品种代码 + `earnings surprise`、`guidance raised lowered`、`analyst upgrade downgrade`、`insider buying`
推荐来源：Yahoo Finance Analyst Estimates、Seeking Alpha Earnings Transcripts、Nasdaq.com Insider Trading
**数据窗口**：30天

**维度9 - 合约资金流**（⚠️ gTrade 合成资产特有维度，权重应高于平均）

gTrade 是去中心化合成资产平台，**没有传统的 OI 和资金费率**。D9 重设计为：**Spread 分析 + 24h交易量 + 价格方向组合**。

**Spread 分析（gTrade 核心指标）**：
- gTrade 的 `spreadP` 字段反映该品种的流动性成本（类似传统做市商价差）
- spread 越低 → 流动性越好 → 多空博弈更充分
- spread 异常扩大 → 流动性紧缩 → 警惕极端行情
- 各级别 spread 品种：

| Spread 级别 | spread值 | 品种举例 | 信号含义 |
|------------|----------|---------|----------|
| 低 spread | ≤0.3% | GOOGL, MSFT, SPY, QQQ, XAU, BTC | 流动性好，信号可信度高 |
| 中 spread | 0.3%-0.5% | AAPL, NVDA, AMZN, INTC, META | 流动性正常 |
| 高 spread | 0.5%-0.8% | TSLA, AMD, COIN, MSTR, HOOD | 流动性略低，注意滑点 |
| 极高 spread | >0.8% | XPD | 流动性差，信号降权 |

**24h交易量分析（yfinance）**：
- yfinance 提供标的现货的真实成交量（gTrade 合成资产价格跟踪现货）
- 量价组合信号：

| 价格变化 | 成交量变化 | 研判 | 含义 |
|----------|-----------|------|------|
| 涨 | 放量 | ✅ **多头趋势确认** | 量价配合，趋势健康 |
| 涨 | 缩量 | ⚠️ 上涨动能减弱 | 量价背离，注意回调 |
| 跌 | 放量 | ✅ **空头趋势确认** | 资金加速出逃 |
| 跌 | 缩量 | ⚠️ 抛压减缓 | 可能见底或盘整 |

**gTrade 特有信号**：
- **市场开关**：`isStocksOpen` 决定美股能否交易。盘前盘后流动性差，信号降权
- **杠杆限制**：gTrade 股票最高 50×，远高于传统券商，极端杠杆可能放大波动
- **合成资产溢价**：gTrade 价格 vs 现货基准价偏离过大时 → 注意套利压力

**数据来源**：gTrade REST API `spreadP` + yfinance `Volume` + `isStocksOpen`
**数据窗口**：4小时（市场状态实时，spread 来自品种元数据每日刷新）

**维度10 - 机构动向**：
- 搜索关键词：品种代码 + `ETF inflows outflows`、`13F filing`、`insider selling buying`、`short interest percent`
- **ETF流量**：对应ETF的资金流向（如NVDA→SMH/SOX、个股→SPY/QQQ）
- **13F持仓**：知名基金（Baillie Gifford/ARK/Citadel等）的增减持动向
- **内部人交易**：CEO/CFO/Director买卖，>3人同向=强信号
- **做空比例**（Short Float）：>20%=逼空潜力；<2%=缺乏多空博弈
- 信号持续性：ETF流量=短期(日-周)；13F=中期(3-6月)；内部人交易=强信号
- 推荐来源：SEC EDGAR 13F、Fintel、WhaleWisdom
- **数据窗口**：7天

**维度11 - 市场情绪**：
- 搜索关键词：`VIX index`、`equity put call ratio`、`AAII bull bear spread`、`CNN fear greed index`
- VIX是美股"恐慌指数"核心中的核心：

| VIX区间 | 情绪状态 | 信号含义 |
|---------|---------|----------|
| <12 | 极度自满 | ⚠️ 警惕"黑天鹅"，可能过度乐观 |
| 12-20 | 正常 | 中性 |
| 20-25 | 轻度不安 | 关注市场方向 |
| 25-30 | 恐慌 | 🔴 市场恐慌，关注反向做多机会 |
| >30 | 极度恐慌 | 🔴🔴 历史性买点信号（反向指标） |

- Put-Call Ratio >1.0 = 过度看空（反向做多信号）
- AAII Bull-Bear Spread <-20% = 散户极度看空（反向做多）
- CNN Fear & Greed <25 = 极度恐惧
- 推荐来源：CBOE（VIX和Put-Call）、AAII Sentiment Survey
- **数据窗口**：4小时（VIX实时变动）

**维度12 - 技术结构**（gTrade/yfinance K线 优先）：
- 数据源：**yfinance K线** → `GtradeDataProvider.get_technical_indicators()` 自动计算
- 关注：MA20/MA50/MA200多空排列、布林带位置和带宽、ATR波动率、价格在200日分位数、RS vs SPY（相对强弱）
- 信号判断：
  - MA20>MA50>MA200（bullish多头排列）→ 强趋势偏多
  - MA20<MA50<MA200（bearish空头排列）→ 强趋势偏空
  - 布林带宽收窄+低ATR → 酝酿突破
  - 持续跑赢SPY → 资金青睐的相对强势股
- ⚠️ 注意：yfinance K线与gTrade合成价格高度同步（Chainlink DON 喂价跟踪标的现货），日线一致性好
- **数据窗口**：24小时

**维度13 - 公司治理**：
- 搜索关键词：品种公司名 + `board independence`、`share buyback program`、`dividend increase history`、`CEO compensation`
- 关注：
  - 回购计划规模（占市值%）：大幅增加→管理层认为股价低估→利多
  - 分红连续增长年限：>10年="分红贵族"→质量信号
  - 股权结构：创始人控股vs分散持股
  - CEO减持：需区分计划内出售vs恐慌性减持
- 推荐来源：SEC DEF 14A（Proxy Statement）、公司IR页面
- **数据窗口**：30天

**维度14 - 事件驱动**：
- 搜索关键词：品种公司名 + `next earnings date`、`product launch`、`FDA decision date`、`M&A rumor`、`SEC filing investigation`
- 核心事件日历及影响：

| 事件类型 | 影响时长 | 典型波动 |
|----------|---------|----------|
| 季度财报发布 | 1-3天 | ±5-15% |
| FDA药品审批决定 | 1天 | ±20-50%（LLY等医药股） |
| 重大产品发布 | 1-5天 | 中高 |
| M&A公告 | 1-10天 | 高（被收购方↑，收购方↓） |
| SEC调查/诉讼 | 1-30天 | 高（偏空） |
| 投资者日/Analyst Day | 1-3天 | 中 |

- ⚠️ 提前标注未来7-30天的事件日历，事件前降低仓位
- 事件后：关注是否"buy the rumor, sell the news"
- 推荐来源：Earnings Whispers、FDA Calendar、SEC 8-K filings
- **数据窗口**：7天

### 第二步：维度评分

在每个维度根据获取到的数据和信息，分析这些数据和信息对该品种永续合约价格的影响程度打分：
- **最大利多**：1分 — 强基本面支撑，确信做多
- **中性**：0.5分 — 无明确方向或信号矛盾
- **最大利空**：0分 — 强基本面压力，确信做空
- 介于中间的按实际影响程度在0~1之间赋分

**评分注意事项**：
- D6/D7/D8 注意评分方向（见各维度⚠️标记），避免方向反转
- D9 必须结合OI变化+价格方向+资金费率三者综合判断
- 如果某个维度确实搜索不到任何窗口期信息，该维度默认评分为0.5（中性），权重适当降低

### 第三步：权重评估

考虑当前时间（月份、日期）、该品种的行业特征、以及当前市场环境的特殊性，评估每个维度的权重。

**权重调整原则及触发条件**：

| 环境/事件 | 调整 | 逻辑 |
|-----------|------|------|
| **FOMC决议周**（FOMC ± 3天） | D1↑ +0.03~0.05 | 货币政策是市场焦点 |
| **财报季/即将ER**（ER ± 5天） | D6↑ D8↑ D14↑ | 盈利和预期是核心驱动力 |
| **VIX > 25**（恐慌模式） | D11↑ 其他↓ | 情绪主导市场，基本面暂时失效 |
| **VIX < 12**（自满模式） | D11↑（反转预警） | 过度自满预示回调风险 |
| **OI异常变化**（日增>20%或日减>20%） | D9↑ +0.02~0.04 | 合约资金面异常信号 |
| **资金费率极端**（>0.1%或<-0.1%） | D9↑↑ | 永续特有风险信号 |
| **行业轮动期** | D4↑ | 行业配置变化驱动个股 |
| **ETF大幅流入/流出**（连续多日） | D10↑ | 被动资金流向信号 |
| **重大地缘/政策事件** | D2↑ 或 D3↑ | 宏观事件冲击 |
| **新品发布/FDA/并购公告** | D14↑ | 事件驱动主导短期价格 |

所有维度权重之和 = 1.0。默认基准权重：宏观(3维)≈0.20，行业(2维)≈0.15，公司(3维)≈0.20，市场(4维)≈0.30，治理催化(2维)≈0.15。其中D9和D12（永续核心）在默认基准中权重略高。

### 第五步：操作方案生成

基于综合得分和关键维度数据，生成可操作的交易方案。

#### 5.1 方向判断

根据综合得分确定建议方向：
- 综合得分 ≥ 0.55：多头方向
- 综合得分 ≤ 0.45：空头方向
- 0.45 < 综合得分 < 0.55：观望

**多维度交叉确认**（必须满足至少2条才可开仓）：
- 综合得分方向与合约资金流（D9）信号一致
- 综合得分方向与技术结构（D12）信号一致
- 盈利预期（D8）趋势支持该方向

#### 5.2 入场方案

| 项目 | 生成规则 |
|------|----------|
| 建议入场区间 | D12技术结构中的关键支撑位（做多）或阻力位（做空），取自Binance API计算的20日高低点、布林带上下轨、MA支撑/阻力 |
| 入场触发条件 | 价格触及入场区间 ± 0.5%范围 + D9OI方向确认信号 |
| 首次入场仓位 | 基于偏离度：σ=0.05-0.10→0.3×，σ=0.10-0.20→0.3×，σ>0.20→0.5× |

#### 5.3 止损方案

| 项目 | 生成规则 |
|------|----------|
| 止损价位 | 做多：D12计算的20日低点 - 1个ATR；做空：20日高点 + 1个ATR。若无ATR数据，取关键支撑/阻力位外1-2% |
| 止损幅度 | 一般TradFi个股不超过5%，高波动品种（如MSTR、TSLA）不超过7%，ETF/商品不超过3% |
| 止损后观察 | 评估是否为假突破，如D9OI未反转可考虑二次入场 |

#### 5.4 止盈与加仓

| 项目 | 生成规则 |
|------|----------|
| 第一目标位 | 做多：D12技术结构中的上方阻力位（布林上轨或20日高点）；做空：下方支撑位（布林下轨或20日低点） |
| 第二目标位 | 结合D14事件催化目标位或D7估值回归位（如PE回归历史均值对应的价格） |
| 加仓条件 | 盈利达到止损幅度的1.5倍后 + D9OI持续确认，加仓不超过首次仓位 |
| 移动止损 | 盈利达到第一目标后，止损移至成本价；达到第二目标后，止损移至第一目标位 |

#### 5.5 操作方案约束（铁律）

- **中性区间不开仓**：综合得分在0.45-0.55时，仅输出观望建议，不主动开仓
- **维度冲突降仓**：D9 Spread/量与综合得分方向冲突时，仓位减半；D9+D12同时冲突时，不开仓
- **市场关闭保护**：`isStocksOpen=false` 时 → 不新开仓；已有仓位标注"市场关闭中"
- **高 Spread 降仓**：gTrade spread > 0.6% → 仓位降一档（流动性差，滑点风险大）
- **事件前保护**：品种有未来24h内财报/FDA/重大事件时，标注"建议事件落地后再操作"
- **无数据不开仓**：D9和D12均无有效数据时，标注"数据不足，不建议开仓"

## 注意事项

- 所有搜索必须实时执行，严禁使用过时缓存或记忆
- 如果某个维度确实搜索不到任何窗口期信息，该维度默认评分为0.5（中性），权重适当降低

- **窗口期差异化**：实时数据4h / 日度数据24h / 周度数据7d / 月度数据30d
