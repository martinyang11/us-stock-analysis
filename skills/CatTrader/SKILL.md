# CatTrader — 基于CANN评分的TradFi趋势跟踪交易系统 v3.4

## 概述

CatTrader是基于SA+CANN评分体系的量化交易决策系统，适配 Binance USDT-M TradFi永续合约。每4小时执行一次（6次/天），读取最新SA评分（14基本面+24技术面），CANN推理后通过统一仓位映射表完成品种筛选、杠杆管理和持仓监控。

## 数据流

```
CANN 每日管线（UTC 00:15，每日一次）
  ├── SA全维度评分 dim1-dim14（14基本面） + tech1-tech24（24技术面，Binance自动采集）
  ├── 回填昨日y值（Binance真实涨跌→sigmoid映射）
  ├── 微调模型（仅用有效样本：真实SA+真实y）
  └── 全品种推理 → 35品种综合评分 s ∈ [0,1]

CatTrader（每4小时，6次/天 UTC 00:00/04:00/08:00/12:00/16:00/20:00）
  ├── 读取最新SA评分（来自daily_scores CSV）
  ├── 加载CANN模型 + 推理 → 35品种综合评分s
  ├── 查表 → 确定每个品种的目标杠杆
  ├── 对比当前持仓 → 推导动作（开/平/调/持）
  └── 品种筛选 → 输出决策报告
```

**模型训练由CANN 00:15管线负责，CatTrader只做推理和决策。**

## 仓位映射表（核心）

统一定义5个区间，多空对称：

```
s:  0 ════ 0.35 ════ 0.45 ════ 0.55 ════ 0.65 ════ 1
    │空0.5× │ 空0.3×  │  平仓   │ 多0.3×  │多0.5× │
    │ σ≥0.15│ σ∈[0.05,0.15)│ σ<0.05 │ σ∈[0.05,0.15) │ σ≥0.15 │
```

| 区间 | s范围 | 偏离度σ | 目标杠杆 | 方向 | 含义 |
|------|-------|---------|---------|------|------|
| 强空 | s ≤ 0.35 | σ ≥ 0.15 | 做空 0.5× | SHORT | 评分显著偏离中性，强做空信号 |
| 弱空 | 0.35 < s ≤ 0.45 | σ ∈ [0.05, 0.15) | 做空 0.3× | SHORT | 评分一般偏离，弱做空信号 |
| 中性 | 0.45 < s < 0.55 | σ < 0.05 | 0（平仓） | NONE | 评分接近0.5，无方向性信号 |
| 弱多 | 0.55 ≤ s < 0.65 | σ ∈ [0.05, 0.15) | 做多 0.3× | LONG | 评分一般偏离，弱做多信号 |
| 强多 | s ≥ 0.65 | σ ≥ 0.15 | 做多 0.5× | LONG | 评分显著偏离中性，强做多信号 |

其中 σ = |s - 0.5|（偏离度）。

## 杠杆含义

每个品种独立拥有杠杆倍数作为仓位水平：

- **0.5×**：半仓，表示对该品种有较强信心
- **0.3×**：轻仓，表示有一定信号但信心一般
- **0×**：空仓/平仓，表示无方向性信号

多品种杠杆**独立计算，不叠加**。例如：同时持有NVDA 0.3×做多 + XAU 0.5×做空，各自独立管理。

## 开仓约束（铁律）

**品种必须处于平仓区之外（s ≤ 0.45 或 s ≥ 0.55）才能开仓。**

此约束由双重机制保证：
1. `select_candidates()` 只从目标为LONG或SHORT的品种中筛选，中性区(Direction.NONE)品种自动排除
2. `get_target_leverage()` 将中性区(0.45 < s < 0.55)映射为Direction.NONE，leverage=0

中性区品种永远不会成为cmax/cmin候选，也永远不会触发开仓动作。

## 决策推导（统一规则）

查表得到目标杠杆后，与当前持仓对比推导动作：

| 当前持仓 | 目标杠杆 | 动作 | 说明 |
|---------|---------|------|------|
| 无仓 (leverage=0) | ≠0 | **开仓** | 信号出现，按目标方向和杠杆建仓（仅平仓区外品种） |
| 有仓 (leverage≠0) | 0 | **平仓** | 信号消失，回归中性 |
| 有仓，同向 | 同杠杆 | **持有** | 信号稳定，维持现有仓位 |
| 有仓，同向 | 不同杠杆 | **调仓** | 信号强度变化，0.3×↔0.5× |
| 有仓 | 反向 | **平仓+开仓** | 信号反转，先平旧仓再开新仓 |

**操作优先级**：平仓（风控） > 反向开仓 > 调仓 > 开仓 > 持有

## 品种筛选

从35品种中各选1个最强信号：

- **cmax**：目标为做多（s ≥ 0.55）的品种中，s最大者 → 最佳做多候选
- **cmin**：目标为做空（s ≤ 0.45）的品种中，s最小者 → 最佳做空候选
- 无品种越过中性区则该方向空缺（不强行选）

**选择逻辑**（Python）：
```python
long_candidates = [(vid, s) for vid, s in scores.items() if s >= 0.55]
short_candidates = [(vid, s) for vid, s in scores.items() if s <= 0.45]

cmax = max(long_candidates, key=lambda x: x[1]) if long_candidates else None
cmin = min(short_candidates, key=lambda x: x[1]) if short_candidates else None
```

## 调度（6次/天，24/7）

| UTC时间 | 美股时段 | 说明 |
|---------|---------|------|
| 00:00 | 收盘后（前日20:00 ET） | 日切后第一拍，现货已收盘，永续正常 |
| 04:00 | 盘前（前日午夜） | 亚洲时段，流动性相对低 |
| 08:00 | 盘前（当日3:00 ET前） | 欧洲开盘前，重要数据可能已发布 |
| 12:00 | 盘前（当日7:00 ET前） | 接近美股开盘，盘前交易活跃 |
| 16:00 | 盘中（11:00 ET） | 美股盘中，流动性最高 |
| 20:00 | 收盘（16:00 ET） | 美股刚收盘，波动可能剧烈 |

**注意**：永续合约24/7不休市，所有时段均执行。周末/节假日流动性可能下降，可考虑降低仓位或暂停。

## 保护机制

### 资金费率保护

永续合约的资金费率是多空力量的重要指标：

| 费率区间 | 保护动作 | 逻辑 |
|----------|---------|------|
| funding > 0.1%（做多拥挤） | 做多仓位 → 降一档（0.5×→0.3×，0.3×→平仓） | 多头拥挤 → 回调风险高 |
| funding < -0.1%（做空拥挤） | 做空仓位 → 降一档 | 空头拥挤 → 逼空风险高 |
| funding ∈ [-0.03%, 0.03%] | 正常 | 市场平衡 |
| funding ∈ [0.03%, 0.1%] 或 [-0.1%, -0.03%] | 警告但不强制降仓 | 偏离但未到极端 |

```python
def apply_funding_protection(target_leverage, funding_rate):
    """资金费率保护：极端费率时降低仓位"""
    if target_leverage > 0 and funding_rate > 0.001:  # 做多+多头拥挤
        return max(0, target_leverage - 0.2)  # 降一档
    if target_leverage < 0 and funding_rate < -0.001:  # 做空+空头拥挤
        return min(0, target_leverage + 0.2)
    return target_leverage
```

### OI过热保护

- 追踪每个品种OI的30日滚动窗口
- OI达到30日历史95%分位 → ⚠️ **OI过热警告**
- OI达到30日历史最高值 → 🔴 **建议暂停开仓**（极端拥挤/恐慌）
- 警告级别不影响现有持仓，仅影响新开仓决策

### 中性区保护

- s ∈ (0.45, 0.55) 时绝不开仓
- 已持仓品种s回归中性区 → 立即平仓

### 维度冲突降仓

- 资金面（D9）与技术结构（D12）与CANN评分方向冲突时 → 仓位减半
- 例：CANN做多，但D9OI显示空头增仓 + D12均线空头排列 → 降至0.15×
- 双重冲突（D9+D12均反对）→ 不开仓

### 事件风险保护

- 品种有未来24h内财报/重大事件 → 标注"建议事件落地后再操作"
- FOMC决议日 ± 4小时 → 所有品种仓位降至0.3×以下

## 输出产物

每次运行输出一份决策报告，保存到 `data/reports/decision_YYYYMMDD_HHMM.md`，含：

1. **执行摘要**：时间、运行次数、当前持仓数
2. **CANN评分分布**：各区间品种数和比例
3. **Top 5 σ品种**：偏离度最大的5个品种
4. **当前持仓状态**：每个持仓品种的方向/杠杆/评分
5. **持仓动作建议**：开仓/平仓/调仓/持有
6. **cmax/cmin分析**：最佳做多/做空候选及理由
7. **风险警告**：费率/OI/事件预警汇总
8. **免责声明**

## 注意事项

- CatTrader仅输出决策建议，**不直接下单**
- 冷启动阶段（无CANN模型/无SA数据）→ 全部s=0.5 → 不会产生任何开仓信号
- 同品种信号反转时：先平旧仓再开新仓（两段操作）
- 止损建议：TradFi美股波动低于加密，个股止损≤5%，ETF/商品止损≤3%
- 仓位上限：单品种不超过0.5×，总杠杆（多+空绝对值之和）不超过2.0×
- 技术面数据：来自CANN管线CSV，CatTrader不直接查Binance API（避免重复请求）
- 所有决策基于截至运行时刻的最新可用数据
- **本系统仅供分析和研究参考，不构成投资建议。永续合约交易具有高风险，可能导致全部本金甚至超额损失。**
