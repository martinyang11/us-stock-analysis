# CatTrader — 基于CANN评分的TradFi趋势跟踪交易系统 v3.4

## 概述

CatTrader基于SA+CANN评分体系的量化交易决策系统，适配 Binance USDT-M TradFi永续合约。每4小时执行一次，读取最新SA评分（14基本面+24技术面），CANN推理后通过仓位映射表完成品种筛选、杠杆管理和持仓监控。

## 数据流

```
CANN 每日管线（UTC 00:15）
  ├── SA全维度评分 dim1-dim14 + 技术面tech1-tech24
  ├── 回填y值 + 微调模型
  └── 全品种推理 → cann_results_{date}.json

CatTrader（每4小时，6次/天）
  ├── 读取最新SA评分（来自daily_scores CSV）
  ├── 加载CANN模型推理 → 35品种综合评分s
  └── 查表 → 对比持仓 → 开仓/调仓/平仓/持有
```

## 仓位映射表

```
s ≤ 0.35       → 做空 0.5×（σ≥0.15）
0.35 < s ≤ 0.45 → 做空 0.3×（σ∈[0.05,0.15)）
0.45 < s < 0.55 → 平仓（中性区）
0.55 ≤ s < 0.65 → 做多 0.3×（σ∈[0.05,0.15)）
s ≥ 0.65       → 做多 0.5×（σ≥0.15）
```

## 品种筛选

从35品种中各选1个最强信号：
- **cmax**：目标做多品种中s最大者
- **cmin**：目标做空品种中s最小者

## 调度（6次/天 UTC）

| UTC | 00:00 | 04:00 | 08:00 | 12:00 | 16:00 | 20:00 |
|-----|-------|-------|-------|-------|-------|-------|
| 美股 | 盘前 | 盘前 | 盘前 | 盘中 | 收盘 | 盘后 |

## 保护机制
- **资金费率保护**：>0.1%→做多降仓；<-0.1%→做空降仓
- **OI过热**：30日极值→警告
- **中性区**：s∈(0.45,0.55)绝不开仓
