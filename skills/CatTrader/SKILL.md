# CatTrader — 基于CANN评分的加密趋势跟踪交易系统 v3.3

## 概述

CatTrader是基于CA+CANN评分体系的量化交易决策系统，适配 Binance USDT-M 永续合约。每4小时执行一次，读取最新CA评分（14基本面+24技术面），CANN推理后通过统一的仓位映射表完成币种筛选、杠杆管理和持仓监控。

## 数据流

```
CANN 每日管线（UTC 00:15，每日一次）
  ├── CA全维度评分 dim1-dim14（基本面，待CA技能填充）
  ├── 技术面自动采集 tech1-tech24（Binance K线）
  ├── 回填y值 + 微调模型
  └── 全币种推理 → cann_results_{date}.json

CatTrader（每4小时，6次/天）
  ├── 读取最新CA评分（来自daily_scores CSV）
  ├── 加载CANN模型推理 → 50币种综合评分s
  └── 查表 → 对比持仓 → 开仓/调仓/平仓/持有
```

**模型训练由每日管线负责，CatTrader只做推理。**

## 仓位映射表（核心，与商品期货版一致）

s ∈ [0,1] 均分为5个区间，多空对称：

```
s:  0 ════ 0.35 ════ 0.45 ════ 0.55 ════ 0.65 ════ 1
    │空0.5× │ 空0.3×  │  平仓   │ 多0.3×  │多0.5× │
    │ σ≥0.15│ σ∈[0.05,0.15)│ σ<0.05 │ σ∈[0.05,0.15) │ σ≥0.15 │
```

| 区间 | s范围 | 目标杠杆 | 含义 |
|------|-------|---------|------|
| 空0.5× | s ≤ 0.35 | 做空 0.5倍杠杆 | σ≥0.15 特别显著 |
| 空0.3× | 0.35 < s ≤ 0.45 | 做空 0.3倍杠杆 | σ∈[0.05,0.15) 一般显著 |
| 平仓 | 0.45 < s < 0.55 | 0（无仓） | σ<0.05 中性区 |
| 多0.3× | 0.55 ≤ s < 0.65 | 做多 0.3倍杠杆 | σ∈[0.05,0.15) 一般显著 |
| 多0.5× | s ≥ 0.65 | 做多 0.5倍杠杆 | σ≥0.15 特别显著 |

## 开仓约束（铁律）

**币种必须处于平仓区之外（s≤0.45或s≥0.55）才能开仓。**

### 加密版新增约束

1. **资金费率保护**：
   - 资金费率 > 0.1%（极端做多拥挤）→ 做多仓位降半或不开启
   - 资金费率 < -0.1%（极端做空拥挤）→ 做空仓位降半或不开启
   - 资金费率保护优先于评分信号

2. **OI过热保护**：
   - OI达到30日历史极值（>95%分位）→ 标记"OI过热警告"
   - 不阻止开仓但强烈提示风险

3. **中性区铁律**（不变）：
   - 0.45 < s < 0.55 的币种永远不会成为候选

## 决策推导（统一规则）

| 当前持仓 | 目标杠杆 | 动作 |
|---------|---------|------|
| 无仓 | ≠0 | **开仓**（仅平仓区外品种） |
| 有仓 | 0 | **平仓**（信号消失） |
| 有仓 | 同向同杠杆 | **持有** |
| 有仓 | 同向不同杠杆 | **调仓**（0.3×↔0.5×） |
| 有仓 | 反向 | **平仓+开仓**（信号反转） |

## 品种筛选

从50币种中各选1个最强信号：
- **cmax**：目标为做多的币种中s最大者
- **cmin**：目标为做空的币种中s最小者
- 无币种越过中性区则该方向空缺

- 资金费率极端时仓位减半保护
